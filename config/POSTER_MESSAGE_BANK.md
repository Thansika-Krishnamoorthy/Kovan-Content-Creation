# Kovan Labs Poster Message Bank

This file contains the approved rotating messages used by the
`canva-poster-template` skill.

## Mandatory usage rules

- Read this file whenever no custom message is supplied by the user.
- Select messages according to the event category identified by the skill.
- Use the rotation index stored in:

```text
/home/thansika/Documents/Content creation/config/message_rotation.json
```

- Replace variables such as `{name}`, `{years}`, `{role}`, and `{event}`
  using the information supplied in the poster request.
- Do not generate a new message when a matching approved message bank exists.
- Do not reuse the same message consecutively for the same event type.
- After message 10, return to message 1.
- Update the rotation index only after Canva editing, SVG export, and local
  saving succeed.
- If a selected message does not fit safely in the Canva template, use the next
  approved message in the same event category.
- Do not modify the meaning of an approved message except for variable
  substitution or minor punctuation needed for correct grammar.
